About Aura

The Engineering Behind the Design

Project Concept

Aura is a minimalist, high-yield workspace built to combat academic procrastination and streamline cognitive focus. By dividing tasks into immediate daily objectives, long-term academic deadlines, and persistent habits, the application structures a student's day without unnecessary clutter.

Technical Stack Breakdown

Layer Technology Used Engineering Purpose
Frontend Layout HTML5 Semantic Tags Provides a clean Document Object Model (DOM) and accessibility.
Aesthetics & UI CSS3 Grid, Flexbox & Variables Powers the midnight dark-theme engine, layouts, and distraction blurs.
Application Logic Vanilla JavaScript (ES6+) Manages the app state machine, client-side routing, and timers.
Data Architecture Cloud PostgreSQL (Supabase) Stores secure relational tables for accounts, item logs, and consistency tracking indices.
